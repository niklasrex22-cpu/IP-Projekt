# Sprachaufnahmen
Eigene Dialektaufnahmen hier ablegen (MP3, WAV, OGG oder M4A), z. B. `be-gruessech.mp3`.
Danach in `src/data/cantons.ts` unter `audioExamples` bzw. bei einem Wort unter `audioUrl` eintragen.
Nur Aufnahmen mit Einverständnis der sprechenden Person verwenden. Siehe README.md, Abschnitt 4.2.
